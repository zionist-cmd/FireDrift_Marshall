Докатка живёт на сервере: по концу оплаченного времени карт гаснет по своему таймеру, сервер сразу шлёт MaxSpeed поменьше и второй Start на окно докатки. Поэтому если сервер упадёт, карт остановится вовремя, а не поедет лишнюю минуту. Окно докатки 0 отключает её совсем. Пароли правятся только в самом файле.

Обслуживание платы — эти кнопки меняют состояние карта

Всё это сеттеры: они пишут в плату то, что пришло в параметрах запроса. Дёрнуть такой адрес без параметров — значит записать пустое значение, так уже стирали имя устройства. Поэтому здесь у каждого своя кнопка с заранее собранными параметрами, а не поле для ввода произвольного адреса.
