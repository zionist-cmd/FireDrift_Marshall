# FireDrift Marshall

Открытая система управления прокатными дрифт-картами на платах **SmartKart v5.1**:
сервер с панелью маршала, админкой и API для CRM, документация по плате и
восстановленная схема в KiCad.

Сделано для парка FireDrift: 15 картов с контроллерами JKL-36V500W-002 и
платами SmartKart на Wemos D1 mini (ESP8266). Прошивку картов мы не меняем —
сервер говорит с заводской прошивкой на её протоколе.

> **Пароли, токены и образ прошивки в репозитории нет и не будет.** Их хранит
> ответственный и передаёт сотрудникам отдельно. Подробно —
> [docs/bezopasnost.md](docs/bezopasnost.md#доступы).

## Что внутри

| Путь | Что это |
|---|---|
| `marshal.py` | сервер: вебсокет-хаб для картов, панель маршала, админка, API |
| `panel.html`, `admin.html` | панель маршала и админ-панель |
| `fakekart.py` | поддельные карты для проверки сервера без железа |
| `kart_server.py` | подставной сервер для разбора протокола: притворяется заводским сервером, пишет весь обмен, команды руками. Нужен `pip install websockets` |
| `analyze_log.py` | разбор лога по картам: кто отваливается, перезагружается, у кого слабый сигнал и мёртвая педаль. Номера из `karts.conf` |
| `analyze_dump.py` | разбор дампа флеша карта: строки, адреса, IP. Его вывод (`all_strings.txt`) содержит пароли — в репозиторий не класть |
| `*.bat` | ярлыки для кассы: запуск, стоп, лог, автозапуск |
| `hardware/` | схема платы в KiCad 10 и её PDF |
| `docs/` | документация |

## Быстрый старт

Нужен Python 3.7 или новее, больше ничего.

```
python marshal.py
```

или ярлык `Картинг.bat`. При первом запуске рядом появится `marshal.conf` с
настройками и **случайным паролем админки** (строка `admin_pass`).

| Что | Где |
|---|---|
| Панель маршала | `http://<адрес кассы>:8080/` |
| Админка | `http://<адрес кассы>:8080/admin` |
| Подключение картов | вебсокет на тот же порт 8080 |

Карты сами звонят на сервер. Адрес сервера зашит в прошивку карта, поэтому у
кассы должен быть именно этот адрес — см.
[docs/bezopasnost.md](docs/bezopasnost.md#адрес-кассы-зашит-в-прошивку).

Проверить сервер без картов — три поддельных карта на локальный сервер:

```
python fakekart.py
```
