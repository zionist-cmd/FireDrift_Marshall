# FireDrift — электрокарты клуба

Сервер картов, разобранная прошивка плат и база знаний для ИИ-помощника по ремонту.

## Как всё устроено

- **Касса** — Windows-ПК. На ней CRM (`fdcrm.exe`), она запускает **маршал**
  (`marshal.py`, порт 8080) — сервер картов. Закрыть окно CRM = остановить всё.
- **Карт:** батарея 36 В (3 × 12 В) → реле на плате → контроллер → мотор-колесо.
  Педаль газа и переключатель I/O на корпусе.
- **Плата SmartKart** на каждом карте: Wi-Fi-модуль D1 mini (ESP8266) + АЦП/ЦАП
  PCF8591 + реле. Читает педаль, выдаёт газ на контроллер с учётом лимита скорости,
  по Wi-Fi держит связь с маршалом.
- **Сеть:** карты — в Wi-Fi роутера Keenetic, касса подключена к нему кабелем.
- **Заезд:** CRM или панель маршала → маршал включает реле, ставит лимит, ведёт
  время кусками по 9 минут (так требует прошивка), в конце — минута докатки на малой
  скорости, потом стоп.
- **Защита:** маршал сам останавливает карт при сбое платы (газ мог уйти выше
  лимита) и при «местном» катании без оплаты, когда сервера не было.

## Где что

| Что | Где |
|---|---|
| Вход для ИИ (Claude): правила и карта знаний | `AGENTS.md` |
| База знаний для ИИ: ремонт, измерения, диагностика, процедуры, история картов | `ai/` |
| Документация: протокол, монтаж, плата, сервер, API для CRM | `docs/` |
| Схемы платы и проводки | `hardware/` |
| Разобранная прошивка платы (без паролей) | `firmware/` |
| Сервер и страницы | `marshal.py`, `panel.html` (маршал), `admin.html` (админка) |
| Инструменты | `usb_log.py` / `USB лог.bat` — лог платы по USB; `kakoy_kart.py` / `Какой карт.bat` — какой карт подключён; `fakekart.py` — поддельные карты |
| Пароли, адреса, таблица плат, образы прошивки | **закрытый** репозиторий `FireDrift_Access` |

## Как пользоваться при поломке

1. Открыть Claude с доступом к этому репозиторию и к `FireDrift_Access`.
2. Написать, что случилось: номер карта, что видели, когда.
3. Делать по одному шагу, как скажет Claude, и отвечать, что видно.

## Для разработки

- На кассе стоит ветка `kassa-sync-reconnect`; правки — через PR в неё.
- Проверки: `python -m unittest discover tests`.
- Запуск на кассе: `Сервер.bat`; журналы — `logs/`.
