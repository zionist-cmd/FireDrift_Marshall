# Прошивка платы карта: как она работает

Разбор заводской прошивки платы SmartKart v5.1 (D1 mini, ESP8266), версия 0.9.10.
Код производителя дизассемблирован 25.11.2026 (Ghidra), часть выводов проверена
на живых платах в тот же день.

- **[разбор прошивки]** — прочитано в коде;
- **[измерено]** — проверено на живой плате или по журналам, с датой;
- **[не проверено]** — вывод из кода, на плате не проверялся.

Исходный текст (псевдо-C, без паролей и адресов): `firmware/decompiled/`.
Таблица строк: `firmware/strings_vendor.tsv`. Как повторить разбор: `firmware/README.md`.
Образы прошивки (заводской дамп и образ с адресом кассы) — только в закрытом
репозитории FireDrift_Access: в них пароль Wi-Fi.

Прошивку на картах **не меняем**: только адрес сервера в образе (`ai/06-instrumenty.md`).
Всё, что ниже плохо, обходится на сервере (`ai/04-marshal.md`).

## 1. Из чего собрана

| Что | Подробности |
|---|---|
| Основа | открытый проект tretyakovsa/Sonoff_WiFi_switch (GPL-3.0): веб-морда, SSDP, `/edit`, OTA, JSON-страницы |
| Сборка | ядро Arduino ESP8266 2.5.x, SDK 2.2.2-dev(38a443e) |
| Библиотеки | вебсокеты Links2004 (клиент к серверу + сервер на порту 81), ESP8266WebServer (порт 80), SSDP, SPIFFS, TickerScheduler, Ticker, DHT (датчика на картах нет), приёмник пульта 433 МГц (RCSwitch), обновление по HTTP |
| Код производителя | 0x40201010–0x4020ac70 во флеше, около 30 КБ, 157 функций |
| Отладка | печатает в USB (115200) по-русски — это видно в `usb_log.py` (`ai/06-instrumenty.md`) |

### Устройство флеша (4 МБ)

| Адрес | Что |
|---|---|
| 0x000000 | загрузчик eboot |
| 0x001000 | программа (код 473 КБ, IRAM 30 КБ, данные 8 КБ) |
| 0x180000 | копия программы для обновления по сети |
| 0x200000 | файловая система SPIFFS, 2 МБ (`config.json` и др.) |
| 0x3FB000 | EEPROM — пусто, не используется |
| 0x3FC000 | настройки Wi-Fi и радио SDK |

Адрес сервера — строки в данных программы, по смещениям в образе
`0x7f847` (13 символов) и `0x7f855` (15 символов), копии в OTA-части
`0x1fe847` / `0x1fe855`. Порт 8080 — число в коде, строкой не меняется.

## 2. Ножки D1 mini [разбор прошивки]

| Ножка | Что | Поле телеметрии |
|---|---|---|
| GPIO12 (D6) | реле K1 — питание контроллера, **единственный настоящий тормоз** | `kOn` |
| GPIO13 (D7) | выход 7 — подсветка | `kOn1` |
| GPIO14 (D5) | вход **переключателя I/O на корпусе** [владелец]: фронт «выкл → вкл» начинает заезд платы; при выключенном I/O газ принудительно холостой | `dIn` |
| GPIO16 (D0) | импульс 3 с в начале каждого заезда (в режиме пульта — импульсы «монет») | — |
| A0 | напряжение на линии переключателя I/O (J7/J8 → R8 → A0): при включённом I/O это батарея, ~40 В, **и при выключенном реле** [измерено: 12.09, №13 25.11] | `aIn` («код_вольты», `974_39.19`) |
| I2C → PCF8591, адрес 0x48 | канал 2 — педаль; каналы 0 и 3 — контроль выхода; ЦАП — газ на контроллер | `adcIn`, `adc0`, `adc3` |

## 3. Что выполняется и как часто [разбор прошивки]

| Период | Функция | Что делает |
|---|---|---|
| 30 мс, таймер SDK | `throttle_tick_30ms` | читает педаль и сразу пишет газ в ЦАП |
| 377 мс, планировщик | `sensors_tick_377ms` | АЦП, батарея, начало заезда по фронту I/O, телеметрия |
| 1000 мс, планировщик | `ride_tick_1s` | таймеры заезда, парковки и ожидания, местный режим, `uptime`, перезапуск через 12 ч |
| каждый проход | `main_loop` | планировщик, веб-сервер, SSDP, вебсокет-сервер и клиент |

`setup` запускает по порядку: файловую систему, конфиг, Wi-Fi, пульт, датчики, время,
SSDP, веб-сервер, вебсокет-сервер, задачи, АЦП/ЦАП, вебсокет-клиент.

Планировщик ставит булев флаг тика, без счётчика: если цикл висел 3 с, два тика
пропадают. Поэтому `uptime` (счётчик тиков) **отстаёт** от реального времени при
зависаниях. Длина заезда при этом считается по часам (`time_now`), не по тикам.

## 4. Газ [разбор прошивки, формула подтверждена измерениями]

```
педаль = АЦП канал 2
если I/O выключен, или идёт «Stop», или реле выключено:  газ = 45
иначе если педаль > 85:  газ = (педаль − 85) × Speed / 100 + 85
иначе:                   газ = педаль
записать газ в ЦАП
```

- Норма педали: отпущена 43–45, в пол 182–188 [измерено, сентябрь–ноябрь].
- №12 25.11 на подставке, лимит 75%, педаль 183: `adc0` 156–159, по формуле 158
  [измерено].
- Первые 85 единиц (≈1,67 В) проходят на контроллер **при любом лимите**, а
  контроллер трогается примерно с 1,1 В. Поэтому процент лимита — не процент
  скорости: лимит 0% тоже едет, а 60% дают больше 60% скорости.
  Грубая оценка доли газа: 0,23 + 0,77 × лимит% [не проверено]. Точно — только
  калибровкой на трассе.

### Ошибка шины I2C → газ выше лимита (опасно)

Ни чтение, ни запись по I2C **не проверяют ошибку**. Несчитанная педаль
приходит как 255: плата считает её «в пол» и даёт газ 170 при лимите 50%, 255 при
100% (обычный потолок около 188). `adc0`/`adc3` читаются той же шиной, поэтому 255
в любом из трёх полей — отказ платы, а не педаль. Если шина отказала целиком,
ЦАП держит последнее записанное значение — газ может зависнуть до выключения реле
[не проверено].

№12: `adcIn=adc0=255` минутами во время заездов 09.09 и эпизоды 28.10, 31.10, 22.11
[измерено]. 25.11 на подставке 25 минут без сбоя [измерено] — вероятнее контакт
от вибрации или тока [не проверено]. Сервер на 255 закрывает заезд и 10 минут не
даёт стартовать (`ai/04-marshal.md`, «Защита»).

## 5. Заезд глазами платы [разбор прошивки]

Состояния и сообщения прошивки в USB (по-русски):

1. **`Start`** с сервера: ставит лимит из поля `Speed` команды, включает выход 7,
   `driveOn=1`. `Length` и время старта записывает, **только если катание ещё не
   идёт** (`timeDriveOn=0`). Реле **не** включает.
2. **Ожидание.** Плата ждёт фронта I/O «выкл → вкл». Пришёл — «началось время
   катания»: реле включено, `timeDriveOn=1`, отсчёт `Length`. Не пришёл за 600 с
   от последнего `Start` — «закончилось время ожидания катания»: реле, свет и
   `driveOn` сняты.
3. **Катание** (`timeDriveOn=1`) длится `Length` секунд по часам платы.
4. **Парковка:** лимит 20%, выход 7 гаснет, реле включено («закончилось время
   катания и началось время парковки»).
5. Через 60 с парковки реле выключается, лимит возвращается к `maxSpeed` из
   `config.json` («закончилось время парковки»).

**`Stop`:** газ в 0, через 100 мс реле и выход 7 выключаются, пауза 900 мс, ответ
`Stop OK`, лимит — `maxSpeed` из `config.json`. Плата занята больше секунды.

### Как это использует наш сервер (важно)

Маршал включает реле сам (`/On6`), а I/O у гостя обычно уже включён — фронта нет,
и плата **весь заезд в ожидании** (`DriveON: 1, timeDriveOn: 0` в USB-логе
[измерено 25.11, №12 и №15]). «Предел платы 600 с» — это таймаут ожидания, а не
предел длины заезда. Поэтому сервер режет заезд на куски по 540 с.

**Каждый `Start` в ожидании перезапускает 600-секундный таймер** и берёт `Length` и
`Speed` из команды, не трогая реле и свет. [измерено 25.11 на №15: `Start` на
300-й секунде → `lengthDrive=539`, `Speed=25`, реле и свет не моргнули; на 600-й
реле **не** снято; снято самой платой на 906-й]. На этом построено продление без
Stop (`ai/04-marshal.md`).

Если гость щёлкнул I/O посреди заезда, плата перешла в «катание»
(`timeDriveOn=1`), и `Start` её уже не продлевает [разбор прошивки; сами не
замеряли]. Тогда сервер перевзводит её через `Stop` + `Start` (#22).

## 6. Местный режим — заезд без сервера [разбор прошивки + журналы]

При разрыве вебсокета плата ставит `localModeStart=1`. На ближайшем секундном
тике, если карт свободен (не едет, не паркуется, не ждёт):

- включает выход 7, ставит `driveOn=1`, `Length=600` («активация локального режима»);
- ждёт фронта I/O: кто угодно щёлкнул I/O — карт едет 600 с плюс минута
  парковки, **бесплатно** («началось локальное катание»);
- такие заезды пишутся в `localdrives.json` и `raceslist.txt`; после 149 — блок,
  но первый же `Start` с сервера блок снимает.

Сервер вернулся: не начатый местный режим плата снимает сама на ближайшей секунде
(«завершенеи локального режима»), **начатое катание доезжает до конца**. Если
плата не видит сервер (`remoteMode=0`), режим висит.

Журналы сентября: 188 эпизодов `localModeWaitStart=1`, из них 45 с катанием
[измерено]. Сервер на местное катание у свободного карта шлёт `Stop` (#20).

## 7. Прочее поведение [разбор прошивки]

| Что | Как |
|---|---|
| Перезапуск сам | только после **12 часов** без связи («Связь отсутствует 12 часов! Перезапуск»), перед этим пишет `TimeReboot.json`. Дневные перезагрузки этим не объясняются |
| Режим пульта 433 МГц | при загрузке 500 001 раз читает GPIO14. Если там «дребезг» (>1000 нулей и >1000 единиц), считает, что подключён приёмник пульта: `Start` сразу включает реле, газ рвётся вместе с дребезгом. Признак: растёт `rc_counts`, в USB-логе `rc_swith_on = 1`. На №12 и №15 25.11: `ones= 0 zeros= 500001`, `rc_swith_on = 0` [измерено] |
| Переключение серверов | после каждых 5 разрывов — на второй адрес из таблицы; в нашем образе оба адреса — касса, порт 8080, безвредно |
| Время | NTP `ru.pool.ntp.org`, пояс зашит строкой Самары (UTC+4): часы платы отстают от местных на час [измерено 25.11] |
| Датчик температуры DHT | не установлен: «Sen ok = TIMEOUT / no data» при загрузке — норма |
| `Update` / `UpdateFS` по вебсокету | скачивает и прошивает программу или файловую систему **по любой ссылке без проверки** — кто подменит сервер в Wi-Fi картов, тот перепрошьёт плату |
| `uptime` | счётчик тиков (секунд), отстаёт при зависаниях |
| `DrivePoints` | сумма (`adc0` − 85) по опросам раз в 377 мс, пока идёт катание по I/O (`timeDriveOn=1`) и газ выше 85; обнуляется в начале такого катания. При нашем старте (`timeDriveOn=0`) не растёт. Не признак «едет» |
| Общий конфиг | на всех платах `config.json` от «Kart_4_» (имя, `maxSpeed`), потому что прошит один дамп; различаем платы по DUUID (ID чипа) |

## 8. Команды и адреса платы

### Вебсокет (сервер → плата) [разбор прошивки]

| Команда | Что делает | Ответ |
|---|---|---|
| `{"Command":"Start","Length":N,"Speed":P}` | раздел 5 | `Start OK` |
| `{"Command":"Stop"}` | раздел 5, плата занята ≥ 1 с | `Stop OK` |
| `{"Command":"MaxSpeed","Speed":P}` | лимит 0..100, во флеш не пишет | `MaxSpeed OK` |
| `{"Command":"Status"}` | шлёт строку телеметрии | JSON + `Status OK` |
| `{"Command":"Update"/"UpdateFS","file_url":...}` | перепрошивка по ссылке | `Update OK` |
| остальное | — | `error` |

После подключения плата сама шлёт `Init` со своим DUUID.

### HTTP на порту 80 [разбор прошивки + `docs/protokol.md`]

`/On6`, `/Off6` (реле), `/On7`, `/Off7` (свет), `/maxSpeed?maxSpeed=N`,
`/config.live.json` (живые поля, без пароля), `/config.setup.json`, `/restart`,
`/ssid`, `/ssidap`, `/wifion`, `/wifioff`, `/ssdp`, `/timeZone`, `/Time`, `/rcVal`,
`/charts.json`, `/Sensors`, `/edit`, `/list`, `/description.xml`.
Часть закрыта заводским логином и паролем веб-морды (одинаковые на всех платах;
значение — в FireDrift_Access).

### Файлы на плате (SPIFFS)

`config.json` (имя, Wi-Fi, `maxSpeed`), `raceslist.txt` (журнал местных заездов),
`localdrives.json`, `reboots.json`, `TimeReboot.json`, `rcCode.json`.
Пишутся во флеш: начало и конец местного заезда, `Start` при заблокированных
местных заездах, перезапуск через 12 ч. Серверные `Start`, `Stop`, `MaxSpeed` в
обычной работе во флеш не пишут.

## 9. Сообщения платы в USB (115200)

| Строка | Что значит |
|---|---|
| `Start FS`, `Start WIFI`, …, `Start WebSoketClient` | загрузка, по шагам `setup` |
| `ones= … zeros= …`, `rc_swith_on = 0/1` | проверка режима пульта при загрузке (раздел 7) |
| `WS connect to …`, `[WSc] Connected to url: /` | подключение к серверу |
| `[WSc] get text: {...}` | команда от сервера |
| `[WSc] get pong DriveON: … timeDriveOn: … localModeStart: …` | раз в ~15 с — состояние заезда |
| `[WSc] Disconnected!` | вебсокет оборвался |
| `началось время катания`, `закончилось время ожидания катания`, `…парковки`, `активация локального режима`, `началось локальное катание`, `завершенеи локального режима` | разделы 5–6 |
| `Exception (N)`, `Soft WDT`, `>>>stack>>>` | программа упала — отчёт ядра перед перезагрузкой |
| мусор | загрузчик ESP печатает на 74880 (`rst cause:N`) — на 115200 это мусор, признак перезагрузки |

Причина сброса из загрузчика: 1 — питание, 2 — ножка RST (кнопка, помеха) или
программный перезапуск, 4 — аппаратный сторожевой таймер. Читается только вторым
переходником на 74880 (`ai/06-instrumenty.md`).

## 10. Найденные ошибки прошивки и что с ними сделано

| Ошибка | Опасность | Что сделано |
|---|---|---|
| I2C без проверки ошибок → газ выше лимита | высокая | сервер закрывает заезд при 255 и блокирует старт (#20); №12 не выпускать до проверки |
| Местный режим без сервера | высокая (бесплатные и неконтролируемые заезды) | сервер останавливает местное катание (#20); не перезагружать кассу днём |
| `Stop` роняет реле → блокировка контроллера с нажатой педалью | средняя | продление без `Stop` (#21), перевзвод только при отпущенной педали (#22) |
| `Update` по любой ссылке | средняя | закрыто только паролем Wi-Fi картов |
| Режим пульта по дребезгу I/O | средняя | не исправлено; признак — `rc_swith_on = 1` |
| `uptime` отстаёт при зависаниях | низкая | учитывать при разборе журналов |

Своя прошивка или правка кода производителя — отдельное решение владельца; пока
не делали.
