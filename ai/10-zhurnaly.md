# Журналы: где лежат, как читать, как искать

Где хранится каждый журнал системы, как выглядят его строки, какими командами
PowerShell найти нужное по карту и времени, как перевести таймер панели в часы.
В конце — разобранный случай №13 (25.11) как образец.

Метки: **[измерено]**, **[владелец]**, **[разбор прошивки]**, **[не проверено]**.
Формат журнала маршала описан по коду `marshal.py` (версия 8790002), без меток.

Связанные файлы: как работает маршал и что значат его действия —
`ai/04-marshal.md`; сеть и журнал роутера — `ai/05-set.md`; USB-лог платы —
`ai/06-instrumenty.md`, раздел 4; нормы полей телеметрии — `ai/07-izmereniya.md`;
симптом → шаги — `ai/08-diagnostika.md`; номер карта ↔ DUUID — `ai/09-karty.md`.

## 1. Журнал маршала

### 1.1. Файлы

- Новый файл каждый час: `marshal-2026-11-25_19.log` — строки с 19:00:00 до
  19:59:59. **Дата — только в имени файла**, в строках её нет.
- Около 3 МБ в час, ~30 МБ за смену. Кодировка UTF-8 без BOM.
- Время — часы кассы (местное), с миллисекундами: момент, когда маршал записал
  строку.
- Файл текущего часа маршал держит открытым. `Get-Content` его читает,
  `[IO.File]::ReadAllLines` — падает [измерено 25.11].
- Старые файлы удаляются сами раз в час, самые старые первыми.

### 1.2. Формат строки

```
ЧЧ:ММ:СС.мс   WS <in |out|sys> <кто>           <текст>
```

| Часть | Что это |
|---|---|
| `WS out` | маршал → плата (команда по вебсокету) |
| `WS in` | плата → маршал (ответ, телеметрия) |
| `WS sys` | событие самого маршала: заезд, продление, HTTP к плате, обрыв, защита |
| `<кто>` | DUUID карта; до опознания — его IP; `*` — весь парк |

Примеры формата (строка `Status` — настоящая, №13 25.11; остальные времена и
числа условные):

```
19:03:48.322   WS out 513701         {"Command": "Status"}
19:03:48.328   WS in  513701         Status  driveOn=1  Speed=100  lengthDrive=540  timeDriveOn=0  …  kOn=1  kOn1=1  adcIn=189  adc0=187  adc3=192  aIn=953_38.34  dIn=1  rssi=-51  reboots=108  uptime=22771
19:03:48.329   WS in  513701         Status OK
15:03:15.731   WS sys 192.168.1.x    карт подключился (192.168.1.x:55985)
15:03:15.905   WS sys 12345678       опознан, имя: 7
```

Кроме `WS` бывают:

- `RT  <адрес роутера>  <текст>` — строка журнала Keenetic, если у маршала включён
  `syslog_port` (`ai/05-set.md`, 2.4);
- заставка при запуске: `SMARTKART — сервер картов и панели`, настройки,
  `Заезды до перезапуска: …`;
- строки с `!` — ошибки при запуске; `Traceback (most recent call last):` — падение
  Python.

### 1.3. Телеметрия в строке `Status`

Каждые 6 с на карт (`status_period`). Не весь JSON платы, а выжимка в постоянном
порядке:

```
driveOn Speed lengthDrive timeDriveOn remoteMode localModeStart localModeWaitStart
localModeDriveON blockLokalDrive localDrivesCount DrivePoints timeParking
kOn kOn1 adcIn adc0 adc3 aIn dIn rssi reboots uptime
```

Что значат поля и какие у них нормы — `ai/07-izmereniya.md`. Главное: `kOn` —
реле (1 — карт поедет от педали), `kOn1` — свет, `adcIn` — педаль (отпущена
40–49, в пол 180–189, `255` — сбой), `adc0` — газ на контроллер, `aIn` —
«код_вольты» батареи после реле, `timeDriveOn` — 0 плата «ждёт», 1 «считает
сама», `uptime` — сброс означает перезагрузку. События короче 6 с можно не
увидеть.

### 1.4. Ответы платы и команды

| Строка | Что это |
|---|---|
| `WS out … {"Command": "Status"}` | опрос |
| `WS out … {"Command": "Start", "Length": 540, "Speed": 50}` | старт или продление куска |
| `WS out … {"Command": "Stop"}` | конец заезда, продление через Stop, защита |
| `WS in … Status OK`, `Start OK`, `Stop OK`, `MaxSpeed OK` | плата выполнила |
| `WS in … error` | плата не поняла команду (например, `stop` строчными) |
| `WS in … <кусок JSON с мусором>` | битый кадр, следом обрыв с причиной `битые байты` или `мусор` |

### 1.5. Ключевые строки событий (`WS sys`)

Искать по ним удобно частью текста, без чисел.

**Связь**

| Строка | Что значит |
|---|---|
| `карт подключился (192.168.1.x:порт)` | плата открыла вебсокет (ещё под IP) |
| `опознан, имя: N` | плата назвала DUUID; дальше строки идут под DUUID |
| `заезд восстановлен после обрыва связи` | вернулся посреди заезда, заезд взят из слепка |
| `вернулся на связь и едет сам — не трогаю. У сервера N с, карт: …` | терял только вебсокет, едет по своему таймеру |
| `карт вернулся стоящим — возвращаю ride\|crawl, осталось N с, лимит L` | плата перезагрузилась, маршал вернул заезд |
| `карт отключился — <причина> \| на связи N с, последний кадр N с назад` | обрыв; причины — таблица 1.6 |
| `ошибка отправки: …` | не смог записать в сокет: карт уже отвалился |

**Заезд**

| Строка | Что значит |
|---|---|
| `заезд N мин, скорость «X» (L)` или `ТЕСТ-ДРАЙВ N мин, …` | старт; L — лимит. Хвост `, кусками по 540 с (предел платы)` — заезд длиннее 8 мин |
| `СRM: старт заезда N мин` | старт пришёл из CRM (идёт сразу после строки `заезд …`). **Буква С в `СRM` — кириллическая**: поиск по латинскому `CRM` её не найдёт, искать `RM:` |
| `старт отменён: заезд уже закрыт` | пока шёл старт, заезд закрыла защита |
| `СВЕРКА ride: сервер N с \| карт driveOn=… lengthDrive=… timeDriveOn=… Speed=… \| …` | на каждый `Status` в заезде: N — **сколько осталось по часам маршала** (то, что показывает таймер панели) |
| `продление без Stop: кусок N с, лимит L` | бесшовное продление |
| `продление без Stop не подтвердилось за 20 с — продлеваю через Stop` | плата не приняла `Start`, дальше старый путь |
| `продление заезда: кусок N с, всего осталось M с` | продление через Stop: свет и реле гасли ~2 с |
| `продление отменено: заезд уже закрыт` | пока ждали `Stop OK`, заезд закрыли |
| `после продления реле выключено (kOn=0) — повторяю разрешение` | после Stop реле не вернулось, маршал досылает |
| `после продления реле так и не включилось — карт стоит, проверьте` | **карт стоит с гостем** — нужен человек |
| `щелчок I/O посреди заезда, педаль нажата (adcIn=N) — перевзведу, как только отпустят` | гость включил I/O после старта, ждём отпускания педали |
| `щелчок I/O посреди заезда, педаль отпущена (adcIn=N) — перевзвожу плату, …` и `перевзвод после щелчка I/O: кусок …` | перевзвод: свет мигнул один раз |
| `щелчок I/O снова после 2 перевзводов — больше не перевзвожу, продления через Stop` | у платы фронт I/O бывает сам |
| `докатка: выход 7 снят, лимит L` | оплаченное время вышло, началась докатка |
| `докатка: карт стоит, повторяю набор команд` | на докатке `driveOn` не 1 |
| `заезд закончен` / `остановлен вручную` / `ЗАЩИТА: …` | конец заезда и причина |
| `заезд снят вручную, карт не на связи` | «Стоп» на карточке «нет связи» |
| `СТОП ВСЕМ (N)`, `СRM: заезд остановлен`, `СRM: СТОП ВСЕМ (N)` | остановки из панели и CRM |

**Команды плате по HTTP (желаемое состояние)**

| Строка | Что значит |
|---|---|
| `разрешаю движение → http://…/On6 — ок` | реле включено |
| `снимаю разрешение → http://…/Off6 — ок` | реле выключено |
| `выход 7 поднят → …/On7 — ок`, `выход 7 снят → …/Off7 — ок` | свет |
| `лимит N% → http://…/maxSpeed?maxSpeed=N — ок` | лимит |
| `… — НЕ ПРОШЛО: <ошибка>` | запрос не дошёл (таймаут, отказ); маршал дошлёт |
| `разрешение движения отложено: карт не на связи, дошлю сам`, `СТОП отложено: …`, `лимит N% отложен: …` | карт не на связи, команда ждёт его возвращения |
| `СДАЮСЬ: <разрешение движения\|лимит\|выход 7> не подтвердилось за 4 попыток — смотри плату` | 4 досылки не помогли — дело в плате |

**Защита и сторож**

| Строка | Что значит |
|---|---|
| `ЗАЩИТА: сбой платы: adcIn=255 — … — останавливаю карт` | сбой шины I2C, газ мог уйти выше лимита. **Опасно** |
| `ЗАЩИТА: сбой платы: … К гостям не выпускать, проверить плату` (без «останавливаю») | то же при выключенном реле |
| `ЗАЩИТА: катается в местном режиме без оплаты — сервера не было на связи — останавливаю карт` | местное катание остановлено |
| `ЗАЩИТА: плата в местном режиме, катание не начато` | только запись; сразу после перезапуска маршала у всех — норма |
| `ЗАЩИТА: плата в местном режиме посреди заезда` | только запись |
| `ВНИМАНИЕ: driveOn=1 вне заезда уже N с — проверь карт, автоматический Stop отключён` | свободный карт держит реле (проверяется `kOn`, хотя в тексте `driveOn`) |

**Настройки и сервер**

| Строка | Что значит |
|---|---|
| `лимит скорости задан: N` | ползунок в панели |
| `СRM: лимит скорости N%` | лимит из CRM |
| `лимит докатки: …`, `лимиты по градациям: …`, `настройки изменены из админки` | правки в админке |
| `Заезды до перезапуска: возвращено N — …` / `идущих не было.` | маршал запустился (или перезапущен) |
| `цикл желаемого состояния: …`, `запись заездов: …` | ошибка внутри маршала |
| `ВНИМАНИЕ: заезды не записаны в …rides-state.json: …` | заезды не переживут перезапуск |

### 1.6. Причины обрыва

| Причина в строке `карт отключился — …` | Что значит |
|---|---|
| `плата закрыла соединение` | плата сама закрыла сокет — решение её прошивки |
| `плата закрыла вебсокет (close N)` | то же, по правилам вебсокета, с кодом |
| `соединение сброшено со стороны платы (WinError 10054)` | сброс с той стороны: обычно плата переподключала Wi-Fi |
| `Windows оборвала соединение сама (WinError 10053): …` | плата перестала подтверждать данные или у кассы пропала сеть; у нескольких сразу — касса |
| `плата перестала подтверждать данные (таймаут TCP)` | плата замолчала: зависла, пропало питание или радио |
| `мусор вместо заголовка кадра …`, `в текстовом кадре битые байты …`, `кадр длиной N байт …`, `служебный кадр …` | поток сбился: плата прислала обрезанный кадр |
| `соединение оборвалось посреди кадра …` | связь пропала на середине кадра |

`на связи N с` — сколько прожило соединение; `последний кадр N с назад` — сколько
плата молчала перед обрывом. Как отличить причину по журналу роутера и `uptime` —
`ai/05-set.md`, 6.3.

## 6. Прочие источники

- **Журнал вебсокета в админке** — быстрый взгляд без файлов: последние 200 строк,
  `→` команда, `←` ответ, `·` событие. После перезапуска маршала пуст.
- **События заездов** (`/api/v1/events?since=0`, нужен токен API): `start` (минуты,
  тест, лимит, докатка) и `finish` (причина, когда начат). Это то, что видит CRM.
- **Журналы платы** через админку («Прямой HTTP к плате»): `raceslist.txt` — пары
  «начало конец» в секундах от полуночи **по часам платы**, а они отстают от
  местного времени на 1 час (пояс Самары) [измерено 25.11]; `reboots.json`,
  `localdrives.json` — местные заезды.
- **Журнал Windows кассы** — когда касса перезагружалась (23–24.11 так нашли 6
  массовых обрывов):

  ```powershell
  Get-WinEvent -FilterHashtable @{LogName='System'; Id=1074,6005,6006,6008,41} -MaxEvents 20 | Select-Object TimeCreated, Id
  ```

  1074 — кто-то или что-то запросил перезагрузку (в сообщении — кто), 6005 —
  Windows загрузилась, 6006 — штатное выключение, 6008 и 41 — выключение без
  штатного завершения (питание, зависание).

## 7. Поиск в PowerShell

Команды для PowerShell 5.1 на кассе, по одной. На ноутбуке те же команды, но
путь `kart-marshal\logs\`.

### 7.1. Перед поиском

- **Всегда `-Encoding UTF8`** у `Get-Content` и `Select-String`. Без него кириллица
  читается мусором, и шаблоны с русскими словами ничего не находят.
- Если в окне вместо русских букв кракозябры:

  ```powershell
  [Console]::OutputEncoding = [Text.Encoding]::UTF8
  ```

### 7.6. Телеметрия карта коротко

Шаблон один раз:


```powershell
Get-Content $log -Encoding UTF8 | Where-Object { $_ -match 'WS in\s+513701\s+Status ' -and $_ -match '^19:0[34]' } | ForEach-Object { if ($_ -cmatch $rx) { "{0} kOn={1} kOn1={2} adcIn={3} adc0={4} adc3={5} aIn={6} dIn={7}" -f $Matches[1],$Matches[2],$Matches[3],$Matches[4],$Matches[5],$Matches[6],$Matches[7],$Matches[8] } }
```

## 8. Таймер панели → часы

**Что показывает таймер.** Сколько осталось **оплаченного** времени: конец оплаты
минус «сейчас» по часам маршала. На докатке — сколько осталось докатки («время
доехать до бокса»). На карточке ещё видны часы **запуска** и **конца** оплаты
(на докатке — «стоп»), их можно просто прочитать.

**Формула:**

```
время события = старт + оплаченные минуты − таймер
на докатке:    время события = старт + оплаченные минуты + докатка (60 с) − таймер
```

**Откуда старт:** строка `заезд N мин, скорость …` этого DUUID в журнале маршала
(время строки совпадает с началом отсчёта с точностью до долей секунды) или
запись CRM.

**Посчитать в PowerShell** (старт 18:54:49, 30 минут, таймер 21:00):

```powershell
([datetime]'2026-11-25 18:54:49').AddMinutes(30).AddSeconds(-(21*60 + 0))
```

→ `19:03:49`.

**Без арифметики — по строкам `СВЕРКА`.** На каждый `Status` в заезде маршал
пишет `СВЕРКА ride: сервер N с …`, где N — значение таймера в секундах в этот
момент. Таймер 21:00 = 1260 с; ближайшие строки (опрос раз в 6 с):

```powershell
Get-Content $log -Encoding UTF8 | Where-Object { $_ -match 'WS sys\s+513701\s+СВЕРКА ride: сервер 12[56]\d с' }
```

Если человек помнит только «таймер был около 21» — спросить номер карта и
примерно который был час, найти старт этого карта и посчитать.

## 9. Разбор случая: №13, 25.11, ~19:03 (образец)

Источник — разбор агента на кассе 25.11. Порядок: жалоба → время → строки →

**Жалоба** [владелец]: «при таймере от 21:00 до 20:30 погасла подсветка и

**Шаг 1. Таймер → часы.** Заезд 30 минут из CRM, старт 18:54:49, оплачено до

Stop.

**Что осталось непонятным** [не проверено]:

- по телеметрии свет включён уже в 19:03:48, а владелец видел его погасшим

- в 19:03:48 и 19:03:54 `aIn` просел — мотор тянул ток, а это не похоже на «стоял»
  (опрос раз в 6 с, между замерами могло быть что угодно);
- с 19:04:00 педаль не нажимали. В 19:04:16 из CRM стартовал №16 на 10 мин —

**Шаг 5. Что сделали.** PR #22 (25.11 20:12): перевзвод сразу после щелчка I/O
при отпущенной педали (`ai/04-marshal.md`, 3.3). Правило для площадки: I/O

## 10. Частые ошибки при поиске

| Ошибка | Как правильно |
|---|---|
| нет `-Encoding UTF8` — русские слова не находятся | всегда указывать |
| ищут `CRM` латиницей | в журнале `СRM` с кириллической С: искать `RM:` |
| ищут по номеру карта | в журнале DUUID; номер → DUUID по 7.2 |
| ищут дату в строках | дата только в имени файла (и в `fdcrm.log`) |
| смотрят один файл у границы часа | брать оба соседних |
| `[IO.File]::ReadAllLines` на файле текущего часа | `Get-Content` |
| телеметрию берут из `fdcrm.log` | там она прорежена; брать журнал маршала |
| сравнивают время платы с часами кассы | часы платы на 1 час позади; время USB-лога — с ноутбука, сдвиг найти по общему событию |
| ищут события до 25.11 в журнале маршала | 02–05.11 и 08–21.11 потеряны; сентябрь — копии на ноутбуке |
| пересылают USB-лог или журнал роутера целиком | там пароль Wi-Fi и MAC — только нужные строки |
| ждут событие короче 6 с в телеметрии | опрос раз в 6 с; короткое можно не увидеть — смотреть события `WS sys` и USB-лог |
