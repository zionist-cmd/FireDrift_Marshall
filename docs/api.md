# API для CRM

Внешний интерфейс для CRM и ботов. Отдельный от панели: панель ходит по сессии
в куке, внешние системы — по токену в заголовке.

## Доступ

Токен задаётся в `marshal.conf` строкой `api_token`. **Пустой токен — API
выключен целиком**, чтобы случайно не открыть парк наружу. Сам токен в
репозиторий не кладётся — он в файле доступов.

Токен передаётся одним из заголовков:

```
Authorization: Bearer <api_token>
X-Api-Token: <api_token>
```

Адрес: `http://<адрес кассы>:8080/api/v1/...`

## Ответы

Всегда JSON. Успех — `{"ok": true, ...}`, отказ — `{"ok": false, "error": "текст"}`.

| Код | Значение |
|---|---|
| 200 | успех |
| 400 | плохие параметры |
| 401 | нет токена или он неверный |
| 404 | карт не найден |
| 503 | API выключен, в `marshal.conf` нет `api_token` |

Карт везде указывается полем `kart`: **DUUID или номер на кузове**.

## Методы

### `GET /api/v1/karts` — список картов

```json
{"ok": true,
 "karts": [{"duuid": "14851750", "number": "4", "state": "ride",
            "online": true, "left": 312, "minutes": 10, "speed": 60,
            "test": false, "alarm": false}],
 "presets": [5, 10, 20, 30], "test_presets": [1, 2, 3],
 "crawl_seconds": 60, "server_time": 1760270000.0}
```

| Поле | Смысл |
|---|---|
| `state` | `idle` — свободен, `ride` — заезд, `crawl` — докатка |
| `left` | секунд до конца |
| `minutes` | сколько было оплачено |
| `speed` | лимит, 0..100 |
| `alarm` | свободный карт держит разрешение движения (`kOn=1`) дольше 10 секунд — нужен человек. Сам сервер такой карт не глушит |

### `POST /api/v1/start` — старт заезда

```json
{"kart": "4", "minutes": 10, "test": false, "speed": 60}
```

- `minutes` — только из `presets`, для тест-драйва (`"test": true`) — из
  `test_presets`;
- `speed` необязателен; если указан, сохраняется как лимит этого карта;
- карт уже в заезде — 400.

Ответ: `{"ok": true, "duuid": "14851750", "minutes": 10}`.

### `POST /api/v1/stop` — остановить заезд

```json
{"kart": "4"}
```

### `POST /api/v1/speed` — лимит скорости

```json
{"kart": "4", "speed": 45}
```

Лимит сохраняется в `karts.conf`. Если карт сейчас в заезде или на докатке,
применяется сразу.

### `POST /api/v1/stopall` — стоп всем

Без тела. Ответ: `{"ok": true, "stopped": 12}`.

### `GET /api/v1/events?since=<время>` — журнал заездов

`since` — метка времени Unix, отдаются события позже неё. Начать можно с `0`, а
дальше передавать `server_time` из прошлого ответа.

```json
{"ok": true, "server_time": 1760270100.0,
 "events": [
   {"at": 1760270000.0, "event": "start", "duuid": "14851750", "number": "4",
    "minutes": 10, "test": false},
   {"at": 1760270600.0, "event": "finish", "duuid": "14851750", "number": "4",
    "why": "заезд закончен", "minutes": 10, "test": false,
    "started": 1760270000.0}]}
```

Журнал хранится в памяти сервера: последние 500 событий, при перезапуске
пропадают. CRM должна забирать их сама и регулярно.

## Пример

```
curl -H "Authorization: Bearer $TOKEN" http://192.168.1.50:8080/api/v1/karts
curl -X POST -H "Authorization: Bearer $TOKEN" -H "Content-Type: application/json" \
     -d "{\"kart\": \"4\", \"minutes\": 10}" http://192.168.1.50:8080/api/v1/start
```

## Чего API не умеет

- Разрешение движения и подсветку отдельно от заезда.
- Менять настройки сервера и пароли.
- Работать без токена — даже на чтение.
