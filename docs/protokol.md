# Протокол и прошивка

Как карт говорит с сервером и что умеет заводская прошивка.

## Каналы связи

Три канала, путать нельзя.

| Канал | Направление | Что через него |
|---|---|---|
| Вебсокет 8080 | **карт → сервер** | `Init`, `Start`, `Stop`, `MaxSpeed`, `Status`, `Update`, `UpdateFS` |
| HTTP 80 на плате | **сервер → карт** | `/On6`, `/Off6`, `/On7`, `/Off7`, `/maxSpeed`, `/config.live.json`, `/ssdp`, `/restart` |
| Вебсокет 81 на плате | браузер → карт | телеметрия для веб-морды. **Команд не принимает** |

Карт сам звонит на сервер и **никогда не принимает входящих вебсокет-соединений**.
Поэтому проброс портов не нужен. Но HTTP-канал работает только пока сервер
физически достаёт до платы.

**Регистр команд обязателен:** `stop` строчными возвращает `error`.

**Настоящей защиты нет ни на одном канале:** пароля либо нет, либо он
заводской и одинаковый на всех платах — см.
[безопасность](bezopasnost.md#на-картах-нет-авторизации).

## Что измерено про команды

- **`/On6` без `Start`** → карт едет. `Start` без `/On6` → `driveOn=1`,
  но `kOn=0`, карт стоит.
- **`Start`** поднимает и `kOn`, и `kOn1`. **`Stop`** роняет оба.
- `/On7` и `/Off7` перебивают состояние выхода 7 **только до следующей
  команды заезда**.
- **`maxSpeed=0` не останавливает карт**, а даёт самый малый газ.
- При `kOn=1` карт едет с последним лимитом, даже если `driveOn=0`.

**Отсюда главное правило: свободный карт обязан быть разоружён (`kOn=0`).**
Иначе сядет кто угодно и поедет.

## Телеметрия

Полный список полей, которые отдаёт плата:

```
lengthDrive  driveOn  timeDriveOn  timeParking  remoteMode
localModeStart  localModeWaitStart  localModeDriveON
blockLokalDrive  localDrivesCount  DrivePoints
MinDV MaxDV MinV MaxV MinDDV MaxDDV
LastDriveTime  LastParkingTime  LastWaitTime  uptime
Speed  kOn  kOn1  adcIn  adc0  adc3  aIn  dIn  rssi  reboots
rc_coins  rc_val  rc_counts
```

Что из этого реально полезно:

| Поле | Смысл |
|---|---|
| `kOn` | разрешение движения. **Единственный настоящий тормоз** |
| `kOn1` | выход 7, подсветка |
| `Speed` | текущий лимит, шкала **0..100** |
| `adcIn` | педаль, 0..255 |
| `adc0` | выход ЦАП, 0..255 |
| `rssi` | уровень сигнала. Норма −50…−65, ниже −85 связь рвётся |
| `uptime` | секунды с включения. Сброс = плата перезагрузилась |
| `reboots` | счётчик перезагрузок |

## Прошивка

Версия **0.9.10**, основана на открытом проекте
[tretyakovsa/Sonoff_WiFi_switch](https://github.com/tretyakovsa/Sonoff_WiFi_switch),
лицензия GPL-3.0. Производитель платы дописал картовую часть сверху. Мы её не
меняем, только переписываем адрес сервера в образе.

### Что из этого следует

**HTTP и вебсокет крутятся в одном цикле.** Пока плата разбирает HTTP-запрос,
вебсокет не обслуживается. Отсюда правило: к плате ходить редко и по одному
запросу.

**Планировщик теряет тики.** Аппаратный таймер выставляет булев флаг, цикл его
разбирает. Счётчика нет — если цикл завис на три секунды, два тика потеряны
навсегда.

**Отладка в Serial включена.** Плата сама печатает причину разрыва вебсокета
на 115200. Этого достаточно для диагностики без всяких приборов.

### Адреса и ограничения

| Что | Значение |
|---|---|
| Адрес сервера | строки по `0x7f847` (13 символов) и `0x7f855` (15), копия OTA `0x1fe847`/`0x1fe855` |
| Порт | **8080, число в коде.** Патчем строки не меняется |
| Предел заезда | **600 секунд**, какую длину ни пришли |
| Часовой пояс | зашит строкой `SAMT-4SAMST,M3.5.0,M10.5.0/3` — Самара, UTC+4 |
| Веб-морда | заводские логин и пароль прошивки, одинаковые на всех картах. Сервер берёт их из `marshal.conf` |

**Предел в 600 секунд** обходится на сервере: заезд режется на куски по 540
секунд и продлевается.

**Адрес сервера в образе ограничен длиной строки.** Новый адрес должен
помещаться в 13 и 15 символов соответственно.

### Файловая система платы

`config.json` (значения доступа скрыты, они в файле доступов):

```json
{"SSDP":"Kart_4_","ssidAP":"…","passwordAP":"…",
 "ssid":"…","password":"…","timezone":4,"maxSpeed":70}
```

**Имя и пароль Wi-Fi лежат в файле, а не в коде.** Меняются ручкой
`/ssid?ssid=..&password=..` без перепрошивки. Порядок смены пароля — в
[безопасности](bezopasnost.md#на-картах-нет-авторизации).

Имя платы — `/ssdp?ssdp=Kart_7_`.

`raceslist.txt` — журнал заездов самой платы, пары «начало конец» в секундах
от полуночи. В заводском дампе 149 записей, 148 из них ровно по 663 секунды.

**Дамп флеша = пароли.** Любой образ или дамп карта содержит имя и пароль
Wi-Fi площадки открытым текстом. Дампы, образы и вывод `analyze_dump.py` в
репозиторий не класть.
